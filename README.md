# Note Service

REST-сервис для создания и управления заметками. Приложение написано на Java 17 и Spring Boot. Данные хранятся в памяти процесса: после перезапуска сервиса заметки удаляются.

## Требования

- JDK 17 или Docker.
- Maven Wrapper включён в репозиторий (`mvnw` и `mvnw.cmd`).

## Сборка и запуск

Запустить тесты и собрать приложение:

```bash
./mvnw clean package
```

В Windows PowerShell используйте `.\mvnw.cmd clean package`. Запуск локально:

```bash
./mvnw spring-boot:run
```

Сервис доступен на `http://localhost:8080`.

### Docker

```bash
docker build -t note-service .
docker run --rm --name note-service -p 8080:8080 note-service
```

## API

Все запросы используют JSON. Для создания и обновления `title` обязателен и не может быть пустым или состоять из пробелов. `content` может быть строкой или `null`; `tags` — массив строк, поле необязательно.

### Создать заметку

`POST /notes` — возвращает `201 Created` и созданную заметку.

```json
{
  "title": "Покупки",
  "content": "Купить молоко",
  "tags": ["дом", "важное"]
}
```

Пример ответа:

```json
{
  "id": 1,
  "title": "Покупки",
  "content": "Купить молоко",
  "createdAt": "2026-10-25T10:15:30Z",
  "tags": ["дом", "важное"]
}
```

### Получить заметки

- `GET /notes` — список всех заметок.
- `GET /notes?tag=дом` — заметки, содержащие указанный тег.
- `GET /notes/{id}` — заметка по идентификатору.

### Обновить заметку

`PUT /notes/{id}` принимает тот же формат JSON, что и создание, и возвращает обновлённую заметку. Время создания сохраняется.

### Удалить заметку

`DELETE /notes/{id}` удаляет заметку и возвращает `204 No Content`.

Для отсутствующего идентификатора возвращается `404 Not Found`. Ошибки валидации и некорректные аргументы возвращают `400 Bad Request`; тело ошибки содержит время, HTTP-статус, название ошибки и сообщение.

## Структура проекта

- `src/main/java/ru/project/noteservicetask/controller` — HTTP API.
- `service` и `repository` — операции над заметками и хранилище в памяти.
- `dto`, `entity`, `mapper` — модели запросов/ответов, сущность и преобразование данных.
- `exception` — обработка ошибок API.
- `src/test/java` — модульные и контекстные тесты.
